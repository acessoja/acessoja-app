3. COMO APLICAR

1. Use a cópia do acessoja-app com os Cards 04–06 já aplicados.
2. Extraia o ZIP na raiz acessoja-app, que contém a pasta frontend.
3. Substitua os cinco arquivos correspondentes. Não extraia dentro de
   frontend, pois isso criaria frontend/frontend.
4. Confira as diferenças com git diff.

Na pasta frontend, execute:

  flutter analyze
  flutter test test/map_cards_04_06_test.dart test/map_sprint1_test.dart test/frontend_regression_test.dart
  flutter test

Para validar no navegador:

  flutter build web
  flutter run -d chrome

Se o projeto estiver usando FVM, prefixe os comandos com fvm.
Não é necessário Android SDK para esses comandos de teste e web.
