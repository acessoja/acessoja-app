# Catálogo municipal público

**O arquivo `catalogo_anapolis.json` será criado no PC 1.** Execute na raiz
`python manage.py exportar_catalogo_demo --saida dados_iniciais/catalogo_anapolis.json`
com `DATABASE_URL` apontando para a cópia do banco já preenchida com 423 POIs.

Depois de revisar o arquivo, adicione-o ao Git. Os 423 dados reais não fazem
parte do instalador porque o banco pessoal não foi enviado ao chat. Esse
processo não exporta perfis, senhas, denúncias ou avaliações.
